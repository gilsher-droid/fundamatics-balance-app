# Fundamatics Balance App

An interactive, bilingual learning tool for understanding horizontal asymptotes
of rational functions through a balance-scale visual model.

## Features

- Complete Hebrew and English interface
- Automatic RTL/LTR direction switching
- Persistent language preference
- Responsive Fundamatics design system shared with Geometry A to Z
- Keyboard-friendly controls and accessible status messaging
- Polynomial validation and horizontal-asymptote analysis
- No build step or external dependencies

## Run locally

Serve the repository with any static web server, then open `index.html`.

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
